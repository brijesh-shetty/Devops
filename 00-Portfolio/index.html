// who i am

Systems-minded engineer working across ML and the wire.

I like problems that show up at the boundary — where a model meets a packet, where a packet meets a person.

I'm an undergraduate engineering student at BMS College of Engineering, Bengaluru, currently interning at Hewlett Packard Enterprise, where I've been building an AI-powered enterprise threat-detection pipeline that watches network traffic, runs ML inference at streaming speed, and closes the loop by rotating compromised credentials through Vault — with a human in the loop for the highest-severity actions.

Alongside the internship, I've been building Edu_RAG, a local educational RAG system that ingests PDFs, DOCX, and slide decks — including diagrams via OCR — and answers questions over them using hybrid BM25 + dense retrieval, cross-encoder re-ranking, and locally-served LLMs through Ollama. And a capstone gamified learning platform with sandboxed code execution, adaptive AI interviews, and proctored mock tests.

Outside those, my work spans applied ML (an XGBoost taxi-fare model at R² 0.91, a CV-based focus detector), network telemetry (a TCP packet-loss analysis pipeline), and backend systems (a Redis-backed distributed rate limiter). I care about systems that are honest about uncertainty, fast where it matters, and straightforward enough for the next person to change without dread.

★★ Main project / Security · ML · Systems

HPE — Enterprise Network Threat Detection Pipeline

brijesh-shetty / hp · Hewlett Packard Enterprise Internship

A production-shaped SOC backend built during my HPE internship. A 10-stage pipeline ingests raw packets from Zeek/Suricata IDS, ships them via Elastic Beats into Kafka, runs ML inference on streamed features, and — for BLOCK / CRITICAL threats — creates a pending alert that an admin must approve before HashiCorp Vault rotates credentials. Visualised through a 3D WebGL traffic view, a Bento-box dashboard, and a Security Admin Console.

Python FastAPI Kafka Zeek / Suricata HashiCorp Vault ML Inference Human-in-the-loop WebGL
